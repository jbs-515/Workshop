## Essential Bench Components & Prototyping Materials

| Component/Material                | Notes |
|----------------------------------|-------|
| Resistor kit / resistor decade   | Assorted common values, 1/4 W |
| Capacitor kit                    | Ceramic + electrolytic assorted values |
| Inductor assortment              | Basic values for filtering and testing |
| Diode kit                        | Signal diodes, rectifier diodes, Zener diodes |
| LED assortment                   | Different colors and common sizes |
| Transistor kit                   | Basic NPN / PNP BJTs |
| MOSFET assortment                | Common N-channel / P-channel devices |
| Voltage regulators               | Linear regulators (e.g. 3.3 V, 5 V, 12 V) |
| Op-amps / comparators            | Common DIP/SMD references |
| Logic ICs                        | Basic 74HC series gates, flip-flops, counters |
| Microcontroller dev boards       | Arduino / ESP32 / STM32 or equivalent |
| Crystal oscillators / resonators | Common clock values |
| Push buttons / tactile switches  | Through-hole and SMD if possible |
| Toggle / slide switches          | For quick prototyping and replacement |
| Potentiometers / trimmers        | Common values such as 1k, 10k, 100k |
| Connectors assortment            | JST, Dupont, terminal blocks, headers |
| Pin headers / sockets            | Male/female strips, IC sockets |
| Breadboards                      | Full-size and mini |
| Perfboards / prototype PCBs      | For quick builds and rework |
| Jumper wires                     | Male-male, male-female, female-female |
| Hook-up wire                     | Different gauges and colors |
| Coaxial / shielded cable         | For signal-related work |
| Heat shrink tubing               | Multiple diameters |
| Ferrules / crimp terminals       | For cable finishing |
| Test clips / crocodile leads     | Quick measurement and temporary setups |
| Fuses assortment                 | Glass / blade / resettable fuses depending on use |
| Thermal pads / thermal paste     | Useful in power electronics repairs |
| Standoffs / spacers / screws     | PCB and enclosure mounting |
| Double-sided tape / adhesive pads| Temporary mounting and cable fixing |
| Labels / marker tape             | Cable and prototype identification |
