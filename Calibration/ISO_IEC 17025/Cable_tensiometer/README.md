Patrón: banco de fuerza/tensión trazable.

## Procedimiento:

* Identificar tipo de cable/rango.

* Montar el cable patrón o fixture.

* Aplicar tensiones conocidas.

* Comparar lectura del tensiómetro.

* Repetir en varios puntos.

* Verificar histéresis/repetibilidad.

* Ajustar o certificar.

Se usa para cables de control, mandos, sistemas mecánicos y ajustes de tensión.
