Aquí calibras parámetros relacionados con presión estática y dinámica, que se traducen en altitud, velocidad vertical y velocidad indicada.

## Procedimiento general:

* Verificar estanqueidad del sistema.

* Conectar a patrón de presión/vacío.

* Simular puntos de altitud/presión.

* Simular presión diferencial para airspeed.

* Controlar rampas para no dañar sensores.

* Comparar indicación contra patrón.

* Registrar estabilidad, fugas, error y retorno a cero.

* Evaluar contra especificación.

## Puntos críticos:

* No sobrepresurizar.

* Evitar cambios bruscos.

* Verificar fugas antes de medir.

* Respetar unidades: hPa, mbar, inHg, ft, knots.

* Tener claro si se mide presión absoluta, relativa o diferencial.
