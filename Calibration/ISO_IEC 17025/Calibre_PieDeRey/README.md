Patrón: bloques patrón, anillos, patrones escalonados.

Procedimiento:

* Limpiar superficies.

* Verificar cero.

* Comprobar mordazas exteriores, interiores y profundidad si aplica.

* Medir varios puntos del rango.

* Evitar fuerza excesiva.

* Registrar error.

* Comprobar repetibilidad.

* Etiquetar/certificar.

Errores típicos:

* Suciedad en mordazas.

* Mala alineación.

* Presión manual variable.

* No comprobar todo el rango.

* Temperatura no estabilizada.
