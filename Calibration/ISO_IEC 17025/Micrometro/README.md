Patrón: bloques patrón o setting standards.

## Procedimiento:

* Limpiar caras de medición.

* Comprobar cero.

* Usar carraca/fricción constante.

* Medir varios puntos.

* Verificar paralelismo si aplica.

* Registrar error.

* Ajustar cero si procede.

>[!IMPORTANT]
>Punto importante: en dimensional, la temperatura de referencia suele ser 20 °C; no siempre hace falta decirlo como dogma, pero sí conviene mencionar control térmico.
